# Online Education LMS

A modern multi-page LMS website built with HTML, CSS, and vanilla JavaScript.

## Pages
- Home
- Courses
- Course Details
- Dashboard
- My Courses
- Instructors
- About Us
- Contact
- Login
- Register
- Learning
- Profile

## Features
- responsive navigation menu
- course search and category filtering
- form validation with JavaScript
- testimonial slider
- curriculum accordion
- localStorage-driven progress and profile data
- dark/light mode toggle
- polished graduate academy UI

## Run locally
From the project folder, start a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Notes
This is a front-end demo project with no backend. It is structured so a backend can be connected later.
